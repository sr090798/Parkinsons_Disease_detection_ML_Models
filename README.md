# Parkinsons_Disease_detection_ML_Models
Comparative Analysis of Machine Learning Models for Parkinson’s Disease Detection
# ML Classification Project

This project predicts **Parkinson's Disease** using machine learning techniques. It was implemented in Google Colab and includes data preprocessing, model training, evaluation, and visualization.

## Files

- `notebook.ipynb` — Colab notebook with the full code and explanation.
- `dataset/` — Dataset used for the project *(can be uploaded here or provide a link below)*.
- `presentation.pptx` — PowerPoint summarizing the approach, results, and conclusions.
